GOOGLE SETUP

Takes about 5 minutes — free Google Cloud project:

  1. Go to console.cloud.google.com — create a project
  2. Enable Google Sheets API
  3. Enable Google Drive API
  4. Go to APIs & Services → Credentials
  5. Create Credentials → OAuth 2.0 Client ID
  6. Choose Web application
  7. Add your domain to Authorised JavaScript origins
  8. Copy the Client ID → paste in the drawer above

All calls go browser → Google directly. No server involved.
