GOOGLE SETUP

Create a free Google Cloud project — takes about 5 minutes:

  1. Go to console.cloud.google.com — create a project
  2. Search Google Sheets API → Enable
  3. Search Google Drive API → Enable
  4. Go to APIs & Services → Credentials
  5. Click Create Credentials → OAuth 2.0 Client ID
  6. Choose Web application
  7. Under Authorised JavaScript origins add your domain (or http://localhost)
  8. Copy the Client ID → paste it in Settings

All API calls go directly from your browser to Google. No server involved.
